# Provenance and disclosure

## New work

The Lens project, scene, interactions, UI, state machine and the 36 memory prompts in `devpost/memory-place.json` are newly written for this submission.

## Pre-existing content

No pre-existing code is copied into this Lens. The prompts are new and fictional; they are not taken from a clinical questionnaire or from a third-party reminiscence program.

The earlier interview-prep and Bongard prototypes remain outside the submission in `../app-interview/` and `../app-rulespace/`. They are not part of this Lens.

## Third-party assets

No third-party trademarks, copyrighted music or real photos are included. All 3D shapes are generated from Lens Studio primitive meshes.

- UI components: Spectacles UI Kit (Snap), installed from the Lens Studio Asset Library.
- Button icons: the Spectacles icon set (`Icons.lspkg`, Snap), installed from the Lens Studio Asset Library.
- Font: Atkinson Hyperlegible (Braille Institute, SIL Open Font License), imported through Lens Studio.
- Testing: LEAF (Snap), installed from the Lens Studio Asset Library. The design preview image is generated by this repository's own renderer and is not the submission demo.

## Privacy and safety

- No real names, addresses, photos or personal data are used.
- The Lens does not record, identify or follow people.
- The Lens is not a medical device and makes no diagnosis, treatment or clinical claim.
- The experience is designed to be used with a caregiver.

## AI tools

- CLAD and the Lens Studio MCP are used to build the Lens.
- The coding agent is used to plan, write the core and UI code, write LEAF tests and iterate on the build.
